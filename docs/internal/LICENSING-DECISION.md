# Licensing decision record

Code is currently MIT in `LICENSE` and `LICENSE-CODE`. Content and templates retain the existing provisional CC BY-NC 4.0 intent in `LICENSE-CONTENT`; that file is not yet the official CC license text.

Before public release, maintainers should choose deliberately among MIT, Apache-2.0, CC BY 4.0, CC BY-NC 4.0, or all-rights-reserved content. Each option changes reuse rights differently; this record is operational guidance, not legal advice.
