# `maverick dashboard`

```text
maverick dashboard [--open] [--port <port>] [--host <host>] [--no-watch] [--json] [--debug]
maverick dash
maverick lens
```

The server binds to `127.0.0.1` by default. Only loopback hosts (`127.0.0.1`, `localhost`, and `::1`) are accepted. `--open` opens the local address using the OS browser handler. `--json` emits the address and watch configuration. Press Ctrl+C to close the server.
