# Measurement Without Hype

If you want to compare workflows, record separately:
- preparation time;
- generation time;
- human review time;
- correction/rework time;
- number of human interventions;
- tests passed/failed;
- files changed;
- review findings by severity;
- monetary cost only when the tool exposes real usage/cost.

Use the same task, initial commit and acceptance criteria when comparing conditions. If you run only once, call it an exploratory demonstration, not a universal benchmark.
