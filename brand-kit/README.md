# Maverick Brand Kit — Codex handoff

Use this folder as the visual source of truth for Maverick AI Dev Stack.

## Give Codex these files

- `assets/brand/*`
- `styles/design-tokens.css`
- `styles/theme.css`
- `docs/BRAND-GUIDE.md`
- `docs/UI-SPEC.md`
- `CODEX-VISUAL-IMPLEMENTATION-PROMPT.md`

## Recommended integration

Copy this kit into the repository as `brand-kit/`, then tell Codex to read `brand-kit/CODEX-VISUAL-IMPLEMENTATION-PROMPT.md` before changing the site.

The SVG files are intentionally source assets and can be used directly in VitePress, README HTML, GitHub Pages, and favicon configuration.
