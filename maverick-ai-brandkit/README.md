# Maverick AI Brand Kit

Ready-to-use identity package for adapting the Maverick AI product.

## Start here
1. Open `BRAND_GUIDELINES.md`.
2. Give Claude Code the contents of `CLAUDE_ADAPTATION_PROMPT.md` or point it to this entire directory.
3. Treat `tokens/brand.css` and `tokens/brand.json` as the design-token source of truth.
4. Use SVG assets whenever possible.

## Contents
- `assets/logo/svg/` — scalable logo and mark assets.
- `assets/logo/png/` — raster exports for common product usage.
- `assets/icons/` — favicon and application icons.
- `assets/reference/` — approved visual exploration/reference.
- `tokens/` — CSS, JSON and Tailwind-ready tokens.
- `components/` — React SVG logo component.
- `preview/` — standalone HTML brand preview.
- `CLAUDE_ADAPTATION_PROMPT.md` — rebranding prompt for Claude Code.
