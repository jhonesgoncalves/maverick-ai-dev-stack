# Release checklist

## GitHub
- [ ] Repository created, described, and given appropriate topics and visibility
- [ ] Default branch, Actions, Pages, and repository URL configured

## npm
- [ ] Package name availability checked manually
- [ ] `npm login` and `npm whoami` confirmed
- [ ] `npm pack` and package contents audited
- [ ] `npm publish --dry-run` completed
- [ ] Version, licenses, README, repository metadata, and publish command confirmed

## Docs
- [ ] Local build and deploy action pass
- [ ] Pages URL, navigation, mobile layout, links, and SEO reviewed

## Release
- [ ] Git tag, GitHub Release, changelog, and installation test completed
