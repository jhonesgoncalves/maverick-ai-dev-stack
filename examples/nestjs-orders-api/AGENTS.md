# nestjs-orders-api

api de pedidos

## Stack
- Languages: TypeScript
- Frameworks: NestJS
- Package managers: npm

## Verification
- lint: `npm run lint`
- typecheck: `npm run typecheck`
- test: `npm run test`
- build: `npm run build`

## How we work
This project uses Maverick AI. Start every change with `maverick new "<idea>"` and follow the flow skills (`maverick-new`, `maverick-build`, `maverick-review`, `maverick-ship`).
Shared skills, agents and commands live in `.agents/` and are linked into each AI tool; change them there, or with `maverick add`.

- Write the flow's documents (PRD, technical spec, tasks, review) and talk to the user in Brazilian Portuguese (pt-BR), using the section headings given for that language. Write code, identifiers, comments, test names, log and error messages and commit messages in English (en).
