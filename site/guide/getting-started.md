# Getting started

## What

Maverick is a vendor-neutral workflow for AI-assisted changes in existing repositories.

## Why

Explicit scope and context make a change easier to review than an unbounded chat transcript.

## When

Use it for features, bug fixes, refactors, migrations, and reviews where a human remains accountable.

## Example

```bash
npx maverick-ai-dev-stack init
npx maverick-ai-dev-stack task add-pagination
npx maverick-ai-dev-stack validate add-pagination
```

## Common mistake

Asking for implementation before recording constraints and acceptance criteria.

## Checklist

- [ ] Task scope is written
- [ ] Context names relevant paths and commands
- [ ] A human will review the diff
