## English

Your AI agent just wrote 1,200 lines. It touched the auth guard, added a dependency and swears "all tests pass."

Would you merge it?

AI made diffs cheap. Trust got expensive. That is why I built Maverick AI, an open-source workflow layer around the agent you already use:

→ One sentence becomes a PRD, a spec grounded in your code and a task graph
→ 7 gates before any merge: artifacts, checks, scope, security, dependencies, diff review and human review
→ The evidence lives in files (PRD.md, EVIDENCE.md, REVIEW.md), not in a chat you closed
→ Lens: a local cockpit for tasks, gates and architecture

It works with Claude Code, Codex, Cursor, Gemini CLI, Copilot, Kiro, OpenCode, Antigravity and Windsurf. 100% local, no telemetry, MIT-licensed.

Maverick never merges. You do.

Try it: npx @maverick-ai/cli init
